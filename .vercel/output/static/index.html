The problem

Generic is easy now. Good is still handmade.

A generated button takes seconds. It usually works, and it usually looks like every other one.

Teressa is for components someone actually thought about: the focus ring, the empty state, the way it behaves in dark mode. Each one is made by a person, and you can see how it came together.

How it works

Build it. Publish it. Hear what people think.

  1. 01

    Build

    Open the editor and write your component against shadcn themes. The preview updates as you type, and drafts save as you go.

  2. 02

    Publish

    Pass the quality checklist, confirm it's human-made, and publish under MIT. Anyone can copy the code or install it with one command.

  3. 03

    Get feedback

    Readers comment on specific lines or answer prompts on accessibility, API design and polish. You mark what you've addressed.

Manifesto

What “human-made” means here.

Every component on Teressa is written, designed and refined by a person. No prompt-to-component tools, and no generated code pasted in.

  1. 01

    A declaration

    Authors confirm each component is human-made when they publish. The declaration is shown on the component's page.

  2. 02

    A visible history

    Drafts autosave with version history, so how a component took shape can be seen, not just claimed.

  3. 03

    Community reporting

    Anyone can report a component they believe was generated. Reports are reviewed under the published guidelines.

An honest limit

This is a community norm, not perfect detection. No tool can reliably tell whether a person wrote a piece of code, and we won't pretend otherwise. What we can do is ask for a clear promise, make the process visible, and give people a way to raise concerns.

FAQ

Questions, answered.

What license are components published under?

MIT by default. That means you can use them in personal and commercial projects, keep the copyright notice, and there's no warranty. Each component page shows its license.

How does “no AI” actually work?

Authors declare each component is human-made when they publish, version history keeps the process visible, and the community can report anything that looks generated. It's a community norm rather than automatic detection, and we're upfront about that.

How much does it cost?

Pricing isn't set yet. Join the waitlist and we'll email you the details when Teressa opens.

Who can publish?

Anyone with an account who makes the human-made declaration and passes the quality checklist.

Is it tied to shadcn/ui?

Yes. Components are built on shadcn/ui and use its theme tokens, and you install them through the shadcn registry. Teressa is an independent project, not an official part of shadcn/ui.
